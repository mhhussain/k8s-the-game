# Asset provenance

- Cluster logo: adaptation of the original SVG paths in `src/ui/brand.tsx` in this repository. No official Kubernetes helm logo is used.
- Launcher icons, launch images and feature graphic: rendered from those paths by `tool/capture_store_test.dart`.
- Store screenshots: actual Flutter widget renders from the same capture tool; no fabricated gameplay or remote images.
- Four WAV effects: original sine-wave compositions generated by `../tools/mobile-audio.py` (run from repository root). No recordings or third-party samples.
- GameSans: bundled Roboto Regular/Bold from the Flutter SDK font distribution. Apache License 2.0, full notice in `fonts/Roboto_LICENSE.txt`.
