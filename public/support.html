Your cluster has a support desk.

Kubernetes: The Game is a complete offline management game for phones and tablets. No account, ads, subscriptions, or in-app purchases.

Contact

Email moohh91@gmail.com. Include the app version, device model, OS version, and steps to reproduce the problem. Attach a save only if you choose; do not include personal or sensitive information.

Save your progress

Open More → Saves & transfers. Use a manual slot or Export current game to keep a JSON backup. Import JSON transfers saves between mobile devices and the web game. There is no automatic cross-device sync.

Why did time stop?

The game pauses when backgrounded and waits for an explicit Resume. Requests can also pause the clock. Editing and help temporarily pause time.

My service will not run

Check image build completion, replica placement, free node slots, node outages, and hardware tags. The Field guide explains every concept offline.

Purchases and refunds

Apple and Google handle payment, downloads, and refunds through their stores. Reinstall using the account that purchased the app. Export your saves before uninstalling.

Privacy

Read the privacy policy. The app does not include analytics or developer crash reporting.
